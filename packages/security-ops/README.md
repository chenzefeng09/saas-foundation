# foundation-security-ops

SaaS Foundation — Security Operations Service.

Platform-level service for SSDLC scan tracking, vulnerability SLA management, SBOM
records/watches, license findings, incident response and security drills.

- API prefix: `/api/security-ops/v1`
- Container port: `8019`
- Schema: `security_ops`
- Tenant context: not required (platform-level)
